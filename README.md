# Práctica 1 — Algoritmos de Ordenamiento

Proyecto correspondiente al curso de Estructuras de Datos y Algoritmos.

## Objetivo

Implementar y comparar diferentes algoritmos de ordenamiento
aplicados a un conjunto de palabras.

## Algoritmos

- Bubble Sort
- Insertion Sort
- Quick Sort
- IntroSort

## Tecnologías

- C++
- STL
- std::vector
- std::chrono

## Estructura del repositorio

- `src/` Código fuente
- `data/` Dataset utilizado
- `docs/` Material para el informe
- `results/` Resultados de las pruebas
- `entrega/` Archivos finales para entregar
